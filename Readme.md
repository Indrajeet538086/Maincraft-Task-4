An interactive, responsive, multi-page web platform built as part of the **Maincrafts Full-Stack Web Development Internship**. This application progresses from foundational modern layout techniques to advanced frontend state management using client-side JavaScript and LocalStorage persistence.

---

## 📌 Project Overview

This project showcases the evolution of a production-ready, client-side web application across four developmental milestones:

1. **Task 1 — Hero & Landing Page Structure:** Semantic HTML5 design paired with modern CSS Grid and Flexbox layouts.
2. **Task 2 — Multi-Page Architecture & Routing:** Seamless cross-page navigation (`Home`, `About`, `Contact`, `Submissions`, and `Dashboard`) with mobile menu toggle interactions.
3. **Task 3 — Client-Side Validation & LocalStorage Persistence:** Form submission handling, strict input verification, and dynamic DOM rendering of stored messages.
4. **Task 4 — Interactive Task CRUD Dashboard:** Full CRUD state operations (Create, Read, Update, Delete), real-time search filtering, status toggles, and live analytics counters.
